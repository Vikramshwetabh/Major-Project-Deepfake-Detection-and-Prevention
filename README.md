# Authentica: AI Powered Deepfake Detection and Prevention 🎭🛡️

An AI-driven system designed to detect and prevent deepfake media content using advanced machine learning, 
computer vision, and signal processing techniques. Developed as part of a B.Tech major project at Jaypee University of Information Technology.

## 📘 Abstract

Deepfakes pose a serious threat to digital authenticity, misinformation, and identity theft. **Authentica** addresses 
this by offering a multi-modal AI-powered system capable of detecting manipulated content in images, videos, and audio.
It leverages deep learning models like **ResNeXt50** and **LSTM** for spatial-temporal analysis, with additional watermarking features for prevention.

---

## 🚀 Features

- 🔍 Deepfake detection for video, audio, and image inputs
- 🧠 Hybrid CNN-LSTM architecture for high detection accuracy
- 🧾 Real-time processing pipeline with batch and sliding-window analysis
- 🔒 Embedded watermarking for video integrity
- 📊 Explainable AI (XAI) integration for result transparency
- ☁️ Cloud-deployable, scalable, and modular system
- 🔐 Advanced security including blockchain-based verification and encryption

---

## 🧪 Technologies Used

### 🧰 Frameworks & Libraries
- **TensorFlow / PyTorch** – Deep learning
- **OpenCV** – Computer vision
- **NLTK** – Text and audio-caption sync

### 🛠 Architecture
- **ResNeXt50**: Spatial feature extraction
- **LSTM**: Temporal pattern analysis
- **CNN**: Image/video classification
- **Watermarking**: LSB-based hidden metadata

---

## 📦 Dataset

- FaceForensics++, DFDC, and custom datasets including manipulated and authentic samples across languages, lighting, and emotions.
